# video-lite

Skill de vídeo curto narrado (explicativo, história, lista, promo, demo) com motion graphics de
verdade — títulos animados, tipografia cinética, símbolos desenhados no traço, geometria sagrada,
diagramas em roda, grade de ícones, transições, partículas — feita para máquinas velhas de 32 bits:
Python + pycairo + ffmpeg + espeak-ng. Sem Node, sem navegador, sem GPU. Veja SKILL.md.

Instalar no jazz: `jazz skill install <url ou pasta>`. Voz sem root: `bash scripts/setup_voice.sh`.
Teste: `python3 scripts/selftest.py`.
